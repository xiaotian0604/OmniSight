🚀 OmniSight SDK 使用示例

重要提示：在使用之前，请确保：
  1. 已经运行 pnpm install 安装依赖
  2. 已经运行 pnpm build 构建 SDK
  3. Gateway 服务正在运行（默认端口 3000）
  4. 已获取有效的 API Key（在 Gateway 管理后台注册项目）

方法 1：使用 IIFE 格式（推荐用于简单 HTML 页面）

直接通过 <script> 标签引入，SDK 会挂载到全局变量 OmniSight：

<!-- 引入 SDK IIFE 版本 -->
<script src="./node_modules/@omnisight/sdk/dist/omnisight.iife.js"></script>

<script>
  // 初始化 SDK
  const tracker = OmniSight.init({
    appId: 'your-app-id',
    dsn: 'http://localhost:3000/v1/ingest',
    apiKey: 'your-api-key',
    enableError: true,
    enablePerformance: true,
    enableReplay: false, // 需要安装 rrweb 依赖
    debug: true,
  });
  
  console.log('OmniSight SDK 已初始化', tracker);
  
  // 手动捕获错误
  tracker.capture({
    type: 'error',
    message: '测试错误',
    stack: new Error().stack,
  });
</script>

方法 2：使用 ES 模块（需要构建工具）

如果你使用 Vite、Webpack 等现代构建工具：

// 在你的项目代码中
import OmniSight from '@omnisight/sdk';

const tracker = OmniSight.init({
  appId: 'your-app-id',
  dsn: 'http://localhost:3000/v1/ingest',
  apiKey: 'your-api-key',
  enableError: true,
  enablePerformance: true,
  debug: true,
});

export default tracker;

方法 3：使用 Import Maps（现代浏览器原生支持）

在没有构建工具的情况下使用 ES 模块：

<!-- 使用 import map 映射模块标识符 -->
<script type="importmap">
  {
    "imports": {
      "@omnisight/sdk": "./node_modules/@omnisight/sdk/dist/omnisight.esm.js"
    }
  }
</script>

<script type="module">
  import OmniSight from '@omnisight/sdk';
  
  const tracker = OmniSight.init({
    appId: 'your-app-id',
    dsn: 'http://localhost:3000/v1/ingest',
    apiKey: 'your-api-key',
    debug: true,
  });
  
  console.log('OmniSight SDK 已初始化', tracker);
</script>

SDK 配置选项

OmniSight.init({
  // 应用 ID（必填）
  appId: 'your-app-id',
  
  // 数据接收地址（必填）
  dsn: 'http://localhost:3000/v1/ingest',
  
  // API Key（可选，用于身份验证）
  apiKey: 'your-api-key',
  
  // 采样率（可选，默认 0.1）
  sampleRate: 0.1,
  
  // 是否启用错误采集（默认 true）
  enableError: true,
  
  // 是否启用性能采集（默认 true）
  enablePerformance: true,
  
  // 是否启用用户行为录制（默认 false，需要安装 rrweb）
  enableReplay: false,
  
  // 隐私配置（可选）
  privacy: {
    maskInputs: true, // 遮盖输入框
    blockSelectors: ['.sensitive-data'], // 屏蔽特定元素
  },
  
  // 是否开启调试模式（默认 false）
  debug: true,
});
